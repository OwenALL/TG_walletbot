# API 契约文档

## 用途

此目录存放前后端 API 契约定义，是前端、后端、QA 三方共同遵守的接口规范。

## 规则

1. **开发前定义**：每个功能在编码前，由 Team Lead 或 backend-dev 定义 API 契约
2. **三方共用**：前端按契约写 API 调用，后端按契约实现路由，QA 按契约写测试
3. **变更通知**：任何契约变更必须通知所有依赖方

## 命名约定

| 约定 | 规则 | 示例 |
|------|------|------|
| URL 路径 | 小写 kebab-case | `/api/v1/bot-configs` |
| 请求/响应字段 | snake_case | `bot_config_id`, `created_at` |
| 分页参数 | 统一格式 | `page` (从1开始), `page_size` (默认20, 最大100) |
| 分页响应 | 统一格式 | `{ items: [], total: N, page: N, page_size: N }` |

## 统一响应格式

### 成功响应
```json
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
```

### 分页响应
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [ ... ],
    "total": 100,
    "page": 1,
    "page_size": 20
  }
}
```

### 错误响应
```json
{
  "code": 40001,
  "message": "参数错误: name 不能为空"
}
```

### 通用错误码

| 错误码 | HTTP 状态码 | 说明 |
|--------|-----------|------|
| 40001 | 400 | 参数错误 |
| 40101 | 401 | 未认证 |
| 40301 | 403 | 权限不足 |
| 40401 | 404 | 资源不存在 |
| 40901 | 409 | 资源冲突（重复） |
| 42901 | 429 | 请求过于频繁 |
| 50001 | 500 | 服务器内部错误 |
